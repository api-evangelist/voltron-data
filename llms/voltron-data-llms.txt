# Voltron Data

> Voltron Data builds Theseus, a GPU-accelerated, composable distributed SQL query engine for petabyte-scale analytics and AI pipelines, and is a major steward of the open-source composable data stack: Apache Arrow, Ibis, Substrait, Arrow Flight SQL, and ADBC. Theseus is distributed embedded through partners rather than as a self-serve public API. ## Open Source

- [sqlflite](https://github.com/voltrondata/sqlflite): example Arrow Flight SQL server implementation with DuckDB and SQLite
- [spark-substrait-gateway](https://github.com/voltrondata/spark-substrait-gateway): gateway speaking the SparkConnect protocol, translating to Substrait
- [substrait-fiddle](https://github.com/voltrondata/substrait-fiddle): prototype, debug, and share Substrait plans
- [substrait-r](https://github.com/voltrondata/substrait-r): R interface to the Substrait cross-language serialization
- [Ibis project](https://ibis-project.org/): the portable Python dataframe library Voltron Data sponsors and helps maintain
